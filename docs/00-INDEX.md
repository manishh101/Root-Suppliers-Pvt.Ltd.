## 🚀 Quick Start

```bash
# 1. Clone and install
cd root-suppliers
pnpm install

# 2. Set up environment
cp .env.example .env.local
# Edit .env.local with your credentials

# 3. Run development server
pnpm dev

# 4. Open http://localhost:3000
```

## 🎓 Prerequisites

Before diving in, you should have basic knowledge of:

- ✅ HTML & CSS basics
- ✅ JavaScript fundamentals (variables, functions, arrays, objects)
- ✅ How websites work (client-server model)
- ✅ Command line basics

If you're missing any of these, check out the [Resources](./18-RESOURCES.md) file for beginner tutorials.
